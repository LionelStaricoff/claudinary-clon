Claudinary - Self-Hosted Image Hosting

A complete alternative to Cloudinary that you can host yourself

What is Claudinary?

Claudinary is a self-hosted image hosting platform that provides similar functionality to Cloudinary but with complete control over your data and infrastructure.

Unlike traditional cloud services, Claudinary runs on your own servers, giving you full ownership of your images and data without relying on third-party services.

Features

Easy Upload

Drag & drop interface for uploading images with support for multiple formats including JPG, PNG, GIF, TIFF, WEBP, HEIC, HEIF, and more.

WebP Conversion

Automatically converts uploaded images to WebP format for optimal web delivery while preserving original files.

Project Organization

Organize your images into projects/folders to keep your content structured and easily accessible.

Direct URLs

Each image gets a unique URL that can be embedded directly in your websites and applications.

Database Storage

All image metadata is stored in a database with H2 (development) or PostgreSQL (production) support.

JWT Authentication

Secure authentication system with JWT tokens for API access and user sessions.

Technologies Used

  • Backend: Spring Boot 4.1.1, Java 25
  • Frontend: Thymeleaf, Bootstrap 5
  • Security: JWT, Spring Security
  • Database: H2, PostgreSQL
  • Image Processing: Thumbnailator, ImageIO
  • API Documentation: SpringDoc OpenAPI
  • Build Tool: Maven
  • Containerization: Docker
